# {CLI_NAME} Resource Management

## Deploying New Edge Compute Networks

<code>{CLI_NAME}</code> deploys an entire ECN from a single YAML file:

<CliBlock>{`{{CLI_NAME}} deploy -f ecn.yaml`}</CliBlock>

You can also deploy individual components:

<CliBlock>{`{{CLI_NAME}} deploy -f controlplane.yaml
{{CLI_NAME}} deploy -f controller.yaml
{{CLI_NAME}} deploy -f agent.yaml
{{CLI_NAME}} deploy -f application.yaml`}</CliBlock>

Deploy commands are idempotent. If a deploy fails, run the same command again.

Platform YAML specs: [Control Plane](../yaml-references/reference-control-plane), [Application](../yaml-references/reference-application).

## Delete Components of Edge Compute Networks

Deleting Control Planes, Controllers, and Edgelet nodes terminates daemons on remote hosts.

<CliBlock>{`{{CLI_NAME}} delete controller alpaca-1
{{CLI_NAME}} delete agent kiwi-1
{{CLI_NAME}} delete application health-care-app
{{CLI_NAME}} delete microservice health-case-ui`}</CliBlock>

To undo a deletion, re-run the deploy command for that resource.

Wipe an entire ECN:

<CliBlock>{`{{CLI_NAME}} delete all`}</CliBlock>

Delete a namespace and its resources:

<CliBlock>{`{{CLI_NAME}} delete namespace zoo-1 --force`}</CliBlock>
