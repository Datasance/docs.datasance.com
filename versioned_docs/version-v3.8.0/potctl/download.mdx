# Download and Install {CLI_NAME}

Platform train **v3.8.0** ships **{CLI_NAME} v{CLI_VERSION}**. Install the binary that matches your distribution.

## Install on macOS

Mac users can use Homebrew:

{FLAVOR === 'datasance' ? (
<CliBlock>{`brew tap Datasance/potctl
brew install potctl`}</CliBlock>
) : (
<CliBlock>{`brew tap eclipse-iofog/iofogctl
brew install iofogctl`}</CliBlock>
)}

## Install on Linux

{FLAVOR === 'datasance' ? (
<>
<p>Install the Debian package:</p>
<CliBlock>{`wget -qO- https://downloads.datasance.com/datasance.gpg | sudo tee /etc/apt/trusted.gpg.d/datasance.gpg >/dev/null
echo "deb [arch=all signed-by=/etc/apt/trusted.gpg.d/datasance.gpg] https://downloads.datasance.com/deb stable main" | sudo tee /etc/apt/sources.list.d/datasance.list >/dev/null
sudo apt update
sudo apt install potctl -y`}</CliBlock>
<p>Or install the RPM package:</p>
<CliBlock>{`cd /etc/yum.repos.d
curl https://downloads.datasance.com/datasance.repo -LO
sudo yum update
sudo yum install potctl`}</CliBlock>
</>
) : (
<>
<p>Install the Debian package:</p>
<CliBlock>{`wget -qO- https://iofog.datasance.com/iofog.gpg | sudo tee /etc/apt/trusted.gpg.d/iofog.gpg >/dev/null
echo "deb [arch=all signed-by=/etc/apt/trusted.gpg.d/iofog.gpg] https://iofog.datasance.com/deb stable main" | sudo tee /etc/apt/sources.list.d/iofog.list >/dev/null
sudo apt update
sudo apt install iofogctl -y`}</CliBlock>
<p>Or install the RPM package:</p>
<CliBlock>{`cd /etc/yum.repos.d
curl https://iofog.datasance.com/iofog.repo -LO
sudo yum update
sudo yum install iofogctl`}</CliBlock>
</>
)}
