# Legacy Agent (v3.7)

:::warning[Deprecated on v3.8.0]

Platform train **v3.8.0** requires **Edgelet v1.0.0+** on every node. Java `iofog-agent`, Agent-Go, and v3.7 field agents are not supported on Controller v3.8.

:::

The Java ioFog Agent and Agent-Go were the v3.7 edge node runtime. For install, configuration, attach/detach, and upgrade procedures, use the [v3.7.3 snapshot](/v3.7.3/agent-management/introduction).

To move to v3.8, follow [Migrating to v3.8.0](/migrating-to-v3-8) and install Edgelet on each node.
