# Edgelet CLI

The Edgelet CLI runs on each Edgelet node. Use it for local configuration, microservice control, image management, and control plane operations on the device.

Start with the root command reference: [edgelet](/edgelet/cli/edgelet).

## Command groups

| Group | Entry point |
| ----- | ----------- |
| Authentication | [edgelet auth](/edgelet/cli/edgelet_auth) |
| Configuration | [edgelet config](/edgelet/cli/edgelet_config), [edgelet init-config](/edgelet/cli/edgelet_init-config) |
| Control plane | [edgelet controlplane](/edgelet/cli/edgelet_controlplane) |
| Deploy / lifecycle | [edgelet deploy](/edgelet/cli/edgelet_deploy), [edgelet deprovision](/edgelet/cli/edgelet_deprovision), [edgelet provision](/edgelet/cli/edgelet_provision) |
| Images | [edgelet image](/edgelet/cli/edgelet_image) |
| Microservices | [edgelet ms](/edgelet/cli/edgelet_ms) |
| Registries | [edgelet registry](/edgelet/cli/edgelet_registry) |
| Runtime classes | [edgelet runtimeclass](/edgelet/cli/edgelet_runtimeclass) |
| System | [edgelet system](/edgelet/cli/edgelet_system), [edgelet system status](/edgelet/cli/edgelet_system_status), [edgelet shutdown](/edgelet/cli/edgelet_shutdown) |
| Shell completion | [edgelet completion](/edgelet/cli/edgelet_completion) |
| Version | [edgelet version](/edgelet/cli/edgelet_version) |
