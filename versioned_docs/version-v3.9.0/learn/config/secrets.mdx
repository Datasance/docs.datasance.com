# Secrets

A **secret** holds sensitive strings on the Controller for one namespace. Keys live in a root `data` block, beside `metadata`.

The short map is [Config, secrets, and volumes](/get-started/workloads/config). Fields are on [Secret fields](/reference/yaml/secret).

This object is the Controller secret. A Kubernetes Secret is a different store, used only when a [certificate authority](/learn/config/certificate-authorities) imports `type: k8s-secret`.

## When to use it

Use a secret for passwords, tokens, and key material. Deploy it before a microservice `valueFromSecret`, before a [volume mount](/learn/config/volume-mounts) that sets `secretName`, and before a certificate authority that imports `type: direct`.

Non-secret settings belong in a [config map](/learn/config/config-maps).

## What deploy does

<CliBlock>{`{{CLI_NAME}} deploy -f secret.yaml -n my-ecn`}</CliBlock>

Deploy looks up `metadata.name`. A missing name creates the secret, including `spec.type` when you set it. The same name updates `data`. Re-deploy sends the `data` map in the file. Prefer `delete secret` when you need to drop a key or rename the secret.

There is no `attach` on the secret. A volume mount publishes it onto Edgelet nodes.

<FlavorYaml title="secret.yaml">

```yaml
apiVersion: {{API_VERSION}}
kind: Secret
metadata:
  name: postgres-creds
  namespace: my-ecn
spec:
  type: Opaque
data:
  username: app
  password: changeme
```

</FlavorYaml>

For `spec.type: tls`, each `data` value is one line of base64-encoded PEM. See [Secret fields](/reference/yaml/secret).

## How a microservice uses it

Set `valueFromSecret` to `secret-name/key`. The secret and the microservice share the namespace.

<FlavorYaml title="env.yaml">

```yaml
apiVersion: {{API_VERSION}}
kind: Microservice
metadata:
  name: line-monitor/reader
spec:
  container:
    env:
      - key: DB_PASSWORD
        valueFromSecret: postgres-creds/password
```

</FlavorYaml>

To mount keys as files, set `spec.secretName` on a volume mount, then use `type: volumeMount`. See [Volume mounts](/learn/config/volume-mounts) and [Microservice fields](/reference/yaml/microservice).
