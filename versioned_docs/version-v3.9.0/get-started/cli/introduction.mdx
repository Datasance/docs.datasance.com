# {CLI_NAME} - Platform Command Line Interface

{CLI_NAME} is the CLI for **{PRODUCT_NAME}**. Use it to install, configure, and operate Edge Compute Networks (ECNs).

You can manage multiple clusters from a single host. Platform train **v3.9.0** supports an in-place upgrade from **v3.8.0**. See [Upgrading to v3.9.0](/release-notes/upgrading-to-v3-9). There is no direct path from v3.7 or older; see [Migrating to v3.8.0](/release-notes/migrating-to-v3-8) first.

The CLI adds fleet catalog commands such as `attach model`, `attach knowledge`, `attach runtimeclass`, and matching `describe`, `detach`, and `delete` helpers. Full syntax is in the autogenerated CLI reference.

Datasance and Eclipse ioFog ship the same feature set under different binary names (`potctl` vs `iofogctl`). Pick the binary that matches your distribution.
