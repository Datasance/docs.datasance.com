# Go SDK

This is the documentation for module `github.com/eclipse-iofog/iofog-go-sdk/v3`. It describes the public API in the current source tree (Controller REST **v3.9** client, EdgeletAPI **v1**, YAML `apiVersion` default **`iofog.org/v3`**). Release notes live in the [module repository](https://github.com/eclipse-iofog/iofog-go-sdk).

The SDK is a library. It does not ship a CLI. <CliName /> and the operator call these packages.
