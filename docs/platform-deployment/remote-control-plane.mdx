# Remote Host - Deploy Control Plane

Every Edge Compute Network ('ECN') starts with a Control Plane that allows us to manage ECN's resources.

In this guide, our Control Plane will deploy a single Controller instance on a remote host.

:::info[We use YAML to define PoT resources]
  <p>The following procedures will define resources in YAML for {CLI_NAME} to consume. Specification of those YAML resources can be found <a href="../yaml-references/reference-control-plane">here</a>.</p>
:::

:::info[Authentication]

Set `auth.mode: embedded` in your Control Plane YAML. See [Embedded OIDC Authentication](/platform-deployment/embedded-oidc) for bootstrap credentials and TLS requirements.

:::

## Deploy a Control Plane on a Remote Host

Create `controlplane.yaml`:

<FlavorYaml title="controlplane.yaml">{`---
apiVersion: {{API_VERSION}}
kind: ControlPlane
metadata:
  name: albatros
spec:
  iofogUser:
    name: Foo
    surname: Bar
    email: user@domain.com
    password: iht234g9afhe
  controller:
    publicUrl: https://38.101.23.2:51121
    consoleUrl: https://38.101.23.2:8008
    package:
      image: {{REGISTRY}}/controller:v3.8.0
  auth:
    mode: embedded
    bootstrap:
      username: admin
      password: LocalTest12!
  systemMicroservices:
    router:
      amd64: {{REGISTRY}}/router:3.8.0
      arm64: {{REGISTRY}}/router:3.8.0
    nats:
      amd64: {{REGISTRY}}/nats:2.14.3
      arm64: {{REGISTRY}}/nats:2.14.3
  events:
    auditEnabled: true
    retentionDays: 14
    captureIpAddress: true
  nats:
    enabled: true
  controllers:
  - name: alpaca-1
    host: 38.101.23.2
    ssh:
      user: bar
      keyFile: ~/.ssh/id_rsa
`}</FlavorYaml>

Edit `host`, `ssh.user`, and `ssh.keyFile` for your remote host. Set `systemMicroservices` arch keys to match the host CPU.

Deploy:

<CliBlock>{`{{CLI_NAME}} deploy -f controlplane.yaml`}</CliBlock>
## Verify the Deployment

<CliBlock>{`{{CLI_NAME}} get controllers`}</CliBlock>
<CliBlock>{`{{CLI_NAME}} describe controller alpaca-1`}</CliBlock>
<CliBlock>{`{{CLI_NAME}} describe controlplane`}</CliBlock>
