## Not deployed

These fields come back from describe. Leave them out of the file you pass to deploy.

```yaml
uuid: "<uuid>" # describe only, string
created: "<timestamp>" # describe only, string
```


`metadata.namespace`, when set, must match `-n`. If `metadata.name` is empty, the name becomes `local`.

## Fields specific to LocalAgent

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `host` | string | No | Legacy host. `spec.config.host` wins for the Controller host. |
| `controllerEndpoint` | string | No | Override Controller URL for provision |
| `airgap` | bool | No | Same as a remote `Agent` |
| `uuid` | string | No | Set after deploy |
| `created` | string | No | Set after deploy |

There is no `ssh` block. Bootstrap runs on the local machine.

For a non-system node, <CliName /> rejects deploy when TCP **54321** is already in use. That port is the default local system node layout.

## `spec.package` and `spec.scripts`

Package and scripts match [Agent fields](/reference/yaml/agent). Local bootstrap sets `LOCAL_INSTALL=1`, so the remote sudo check does not run. See [Bootstrap](/learn/edgelet-nodes/bootstrap).

## `spec.config`

Same structure as `Agent.spec.config`. Paths below are under `spec.config`.

Host resolution for provision and the Controller API:

1. `spec.config.host` when it is non-empty
2. `spec.host`
3. `localhost`

### Identity and geo

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `config.description` | string | No | Free text |
| `config.location` | string | No | Location label |
| `config.latitude` | float | No | Geo latitude |
| `config.longitude` | float | No | Geo longitude |
| `config.arch` | string | Recommended | `amd64`, `arm64`, `arm`, `riscv64`. Synced to `archId`. |

### Runtime

| Field | Type | Default (edge) | Description |
| ----- | ---- | -------------- | ----------- |
| `config.host` | string | See precedence above | Controller host |
| `config.deploymentType` | string | `native` | `native` or `container` |
| `config.containerEngine` | string | `edgelet` | `edgelet`, `docker`, or `podman` |
| `config.containerEngineUrl` | string | Engine default | Socket URL for the engine |
| `config.networkInterface` | string | | Bind interface |

Desktop container on macOS or Windows skips host config materialization. See [Desktop container](/learn/edgelet-nodes/bootstrap#desktop-container).

### Resource limits and logging

| Field | Type | Description |
| ----- | ---- | ----------- |
| `config.diskLimit` | int64 | Disk quota (GiB) |
| `config.diskDirectory` | string | Data directory |
| `config.memoryLimit` | int64 | Memory limit (MiB) |
| `config.cpuLimit` | int64 | CPU limit (%) |
| `config.logLimit` | int64 | Log size limit |
| `config.logDirectory` | string | Log directory |
| `config.logFileCount` | int64 | Rotated log files |
| `config.statusFrequency` | float | Status interval |
| `config.changeFrequency` | float | Change interval |
| `config.watchdogEnabled` | bool | Watchdog |
| `config.logLevel` | string | Log level |
| `config.pruningFrequency` | float | Prune interval |
| `config.availableDiskThreshold` | float | Disk threshold (%) |
| `config.timeZone` | string | Timezone |

### GPS and EdgeGuard

| Field | Type | Description |
| ----- | ---- | ----------- |
| `config.gpsMode` | string | For example `auto` or `off` |
| `config.gpsScanFrequency` | float | GPS scan interval |
| `config.gpsDevice` | string | GPS device |
| `config.edgeGuardFrequency` | float | `0` disables. See [EdgeGuard](/get-started/edgelet-nodes/edgeguard). |

### Router

| Field | Type | Description |
| ----- | ---- | ----------- |
| `config.upstreamRouters` | []string | Upstream router node names. Resolved to UUIDs at deploy. |

| Field | Type | Default (edge) | Description |
| ----- | ---- | -------------- | ----------- |
| `config.routerConfig.routerMode` | string | `edge` | `edge`, `interior`, or `none` |
| `config.routerConfig.messagingPort` | int | `5671` | Messaging port |
| `config.routerConfig.edgeRouterPort` | int | | Interior only |
| `config.routerConfig.interRouterPort` | int | | Interior only |

### NATS

| Field | Type | Description |
| ----- | ---- | ----------- |
| `config.upstreamNatsServers` | []string | NATS server node names. Resolved to UUIDs at deploy. |

| Field | Type | Default (edge) | Description |
| ----- | ---- | -------------- | ----------- |
| `config.natsConfig.natsMode` | string | `leaf` | `leaf`, `server`, or `none` |
| `config.natsConfig.natsServerPort` | int | `4222` | Client port |
| `config.natsConfig.natsLeafPort` | int | `7422` | Leaf port |
| `config.natsConfig.natsClusterPort` | int | | Server only |
| `config.natsConfig.natsMqttPort` | int | `8883` | MQTT |
| `config.natsConfig.natsHttpPort` | int | `8222` | Monitoring HTTP |
| `config.natsConfig.jsStorageSize` | string | `10G` | JetStream storage |
| `config.natsConfig.jsMemoryStoreSize` | string | `1G` | JetStream memory |

Defaults, validation, and deploy processing match [Agent fields](/reference/yaml/agent#deploy-time-processing).

## `configure agent`

Not supported for LocalAgent. The SSH `configure` command applies to remote nodes only. See [Lifecycle](/learn/edgelet-nodes/lifecycle).
