# {CLI_NAME} - Platform Command Line Interface

{CLI_NAME} is the CLI for **{PRODUCT_NAME}**. Use it to install, configure, and operate Edge Compute Networks (ECNs).

You can manage multiple clusters from a single host. Platform train **v3.8.0** is a greenfield release. There is no in-place upgrade from v3.7. See [Migrating to v3.8.0](/migrating-to-v3-8) before you upgrade field deployments.

Datasance and Eclipse ioFog ship the same feature set under different binary names (`potctl` vs `iofogctl`). Pick the binary that matches your distribution.
