# Download and Install {CLI_NAME}

Platform train **v3.8.0** ships **{CLI_NAME} v3.8.0**. Install the binary that matches your distribution.

## Install on macOS

Mac users can use Homebrew:

{FLAVOR === 'datasance' ? (
<CliBlock>{`brew tap Datasance/potctl
brew install potctl`}</CliBlock>
) : (
<CliBlock>{`brew tap eclipse-iofog/iofogctl
brew install iofogctl`}</CliBlock>
)}

## Install on Windows

{FLAVOR === 'datasance' ? (
<p>
Download the Windows binary from{' '}
<a href="https://github.com/Datasance/potctl/releases/tag/v3.8.0-rc.1">Datasance potctl releases</a>.
</p>
) : (
<p>
Download the Windows binary from{' '}
<a href="https://github.com/eclipse-iofog/iofogctl/releases/tag/v3.8.0-rc.1">Eclipse ioFog iofogctl releases</a>.
</p>
)}

### Prepare Windows

To deploy an ECN locally on Windows, configure Docker to run Linux containers:

- Install <a href="https://docs.docker.com/desktop/setup/install/windows-install/">Docker Desktop for Windows</a>
- Follow the WSL2 or Hyper-V backend guidelines in the Docker Desktop docs
- Ensure Docker is running before you use <code>{CLI_NAME}</code>

## Install on Linux

{FLAVOR === 'datasance' ? (
<>
<p>Install the Debian package:</p>
<CliBlock>{`wget -qO- https://downloads.datasance.com/datasance.gpg | sudo tee /etc/apt/trusted.gpg.d/datasance.gpg >/dev/null
echo "deb [arch=all signed-by=/etc/apt/trusted.gpg.d/datasance.gpg] https://downloads.datasance.com/deb stable main" | sudo tee /etc/apt/sources.list.d/datasance.list >/dev/null
sudo apt update
sudo apt install potctl -y`}</CliBlock>
<p>Or install the RPM package:</p>
<CliBlock>{`cd /etc/yum.repos.d
curl https://downloads.datasance.com/datasance.repo -LO
sudo yum update
sudo yum install potctl`}</CliBlock>
</>
) : (
<p>
Download the Linux binary from{' '}
<a href="https://github.com/eclipse-iofog/iofogctl/releases/tag/v3.8.0-rc.1">Eclipse ioFog iofogctl releases</a>.
</p>
)}

## Verify installation

<CliBlock>{`{{CLI_NAME}} version`}</CliBlock>

You should see version **v3.8.0** (or a matching v3.8.0-rc tag).
